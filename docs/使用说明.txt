QSL 邮务台 1.4.4
卡片收发、封发、查验与物流追溯

一、安装与首次使用
双击安装包，按 Windows 提示以管理员权限安装。升级前关闭正在运行的 QSL 邮务台，用原来的 Windows 账户运行安装包，原安装路径会自动带入。覆盖安装保留当前资料。
卸载会清除本机台账、自动备份、台站和打印设置、查询缓存及演示资料。需要保留记录时，可在卸载前将完整备份保存到其他目录。
安装完成页默认勾选「打开 QSL 邮务台」。单击「完成」启动软件。
首次启动时显示空台账和使用引导。勾选「下次不再提示」后，启动时将跳过引导。
在「设置与备份 → 台站资料」中选择个人台站或卡片局，填写名称、本台呼号、经办人和寄件名址。
主界面左侧进入卡片台账、封发作业、物流追踪、单据中心、查验与查单和台站名址。
窗口放大后，文字、按钮和表格会随可用空间放大。打印尺寸按所选纸型和缩放值计算。
右上方可扫描或输入永久卡号、袋号、总封号或物流号，再按回车。Ctrl+F 聚焦扫码框，F5 刷新当前页面。
按 F1 或在「设置与备份」中单击「使用手册」。在目录内选择「名址填写示例」，可切换中文或英文地址。示例资料供阅读和参照填写。

二、卡片逐张管理
在“卡片台账”点击登记卡片。一张实体卡对应一个永久卡号，系统自动生成，例如 QSL-20261118-000001。
可填写进口 / 出口方向、QSO / SWL、原寄和寄达呼号、Via、国家地区、网格、UTC、MHz、模式、RST、设备、天线、功率、邮类和名址。
通联时间按 UTC 填写，格式为 yyyy-MM-dd HH:mm。频率、通联模式和信号报告可按实际记录填写，缺项可留空。
双击卡片或点击“完整溯源”，查看卡片、邮袋、前后运输段和全部关联流转历史。
导入支持 UTF-8 CSV 和 ADIF（.adi / .adif）。CSV 请先用“导出 CSV”获得列名样表。导出保留真实物流号码；再次导入时转为可查询的独立物流绑定。
导入前会显示勾选预览。CSV 按来源卡号去重，原来源卡号保留在历史；ADIF 按呼号、UTC、频率及模式去重。不同来源卡号的实体卡即使 QSO 相同，也分别登记。CSV 空编号的每一行视为一张新实体卡，重复导入前请核对。新导入卡片重新编号，装袋和签收状态不会随 CSV 导入。
已封袋卡片不能直接修改。作废保留永久编号和历史，不物理删除卡片。

三、封发、交接与转寄
建立邮袋，填写起讫台站、方向、航空 / SAL / 水陆、毛重、封志及中转局。
6 位英文字母节点代码为本软件内部代码，例如 QSLAAA / QSLBBB，不宣称是实际分配的邮政 IMPC。
系统按 UPU S8 数据结构生成 20 位总封号，按 S9 数据结构生成 29 位袋号。每次建立邮袋使用独立总封，袋内序号为 001；当前版本不将多个袋合并为一个总封。
袋号含重量（以 0.1 kg 向上取整），因此创建前应称重。填写有误时请使用新的草稿邮袋；旧记录继续保留。
“装入卡片”勾选相同方向且未装袋的卡片。同一卡片不能同时装入两个当前邮袋。
草稿 → 已封袋 → 已交接 → 已接收。封袋先核对件数、重量和封志；交接必须记录接收人 / 地点；接收必须输入实收件数并与清单相符。
如实际少片、多片或破损，应先建立验单记录差异。
已封袋且尚未交接的邮袋可填写原因后重开。交接后的差错通过验单和复验处理。
台站已收到单张实体卡片时，在卡片台账中确认交付。
如果接收后还要转寄，使用“继续转寄”，再装入新的出口邮袋。原卡号、封袋时的清单和以往各段物流继续可查。

四、真实物流与 17TRACK
一张卡片或一个邮袋可以分别绑定多段真实运输号码，包括收寄、国内转寄、国际运输、末端派送和退回。
袋内卡片继承该袋关联的物流信息，转寄后仍能追到之前各段。
选中运单后点“免费查询”，在软件里打开 17TRACK 官方查询页并自动填入单号。可用窗口上的“在浏览器打开”按钮继续查询。
查到节点后点“保存进度”，填写状态、时间、地点和进度说明。可以在同一运单下查阅已保存的节点和早期版本记录的物流轨迹。
物流“已妥投”只代表承运商状态；软件不会据此自动确认台站收到每张卡片。
软件内置的查询窗口需要 Windows 10／11 和 Microsoft Edge WebView2 Runtime。也可在能连接 HTTPS 查询网站的系统浏览器中打开查询页。台账和打印可离线使用。

五、内置单据与打印
单据中心包括附件八份 PDF 的十五个原表面、UPU《公约手册》2026 年 9 月版的 CN／CP 表单及五种辅助单据。
原表的栏线、日戳、签章、段落和印刷字形随原式保留。填报内容使用 QSL 卡片、台站、卡片局和物流字段。UPU 原式的印刷语言随样张保留，录入字段使用中文。
同一张单据的正面与背面合为一个模板。不同纸张规格及用途不同的联次分别选择。含接续表的模板随主表输出。
国际小袋牌 68×46 mm，含 SAL（CP85式）、航空（CP84式）、水陆（CP83式）。公约手册的 CP83／84／85 与 CN34／35／36 袋牌为 130×90 mm，有切角、穿绳位置、发封与收件分栏、S9 条码以及运输与卸载区。
国内袋牌 50×85 mm，分平信、挂信、合封、空袋。
封发卡片清单 150×215 mm，仿邮1301双列 40 格，自动续页、页计和全单计数。
收发卡片路单 145×215 mm，每页 20 格。
验单及复验 130×180 mm，国内查单与查询通联回单 130×205 mm，附件的国际查单正反面为 210×297 mm。
补充模板：S8 总封条码、S9 袋条码、永久卡号标签、QSL 接收交付回执和 RD10 内部未收声明。
UPU 模板可在单据中心用代码、类别或名称查找。列表显示版号、成品尺寸及尺寸依据。尺寸标注有范围的表单保留可选规格。仅有限制或缩印比例的样张会显示本软件采用的规格。
表单用于台站及卡片局内部记录。费用和登记价值由经办人核定后填写。承运商运单号码在「物流追踪」登记。

打印步骤：
1. 双击模板。选择「空白单据」可取得未填写的表单。选择卡片、邮袋或查验记录可带入关联字段。
2. 单击「填写单据」录入字段。表内明细每行一条，各栏用竖线（|）或制表符分隔。已有预设栏位的字段显示在原表。其余手工录入内容随填报附页输出。单击「设置填报位置」，选定字段后在预览的空白栏拖出填报区域，将文字写入所选位置。填写和位置调整仅用于本次输出。
3. 默认“原版尺寸 · 100%”，每一页按成品尺寸输出。旧版保存的 A4 设定会自动切回原版。已选的打印机和明确自行设定的纸型会保留。
4. 需要在整张 A4 上排版时，手动选“A4 拼版”。需要标签卷或其他承印介质时，可选“自定义纸张 / 标签纸”，输入打印驱动所支持的宽高。
5. 打印前将检查驱动实际使用的纸型和可打印范围。若纸型不符，请在驱动中配置对应尺寸，或先导出 PDF。纸张尺寸等于表单尺寸时，软件边距应设为 0。
6. 先打印校准页，测量横纵 100 mm 标尺。驱动中关闭“适合页面”等额外缩放；选择正确进纸方向和纸张类型。
7. 在预览中放大核对文字、栏线及条码。使用「上一页」「下一页」检查正反面。确认后导出 PDF 或打印。
打印设置按模板保存。可选择驱动打印对话框中的打印机、页码和份数。
内置 PDF 保留实际纸张尺寸，常用纸型以 600 dpi 无损保存。较大的自定义纸张会降低图像分辨率以控制内存。保存 PDF 可以直接使用内置功能。
Code 128 条码有校验和两侧静区。74×26 mm 编号签优先使用短扫描编号，也可使用永久卡号来追溯长物流号码。小号 CP 袋牌请配合独立 S9 袋条码，130×90 mm 袋牌已附袋条码。
原栏空间不足时，完整内容随附页输出。CP 91／92 及 CN 45 按封套正面的外尺寸排版。
双面单据按正面、背面的顺序生成在同一份 PDF 中。使用双面打印机时，请在驱动中选定双面及翻转方向。手动翻面时，先选正面页码，翻纸后再选背面页码。首次使用某种纸张请先试印一份。

六、查验与答复
新建验单、复验、国内查单 / 回单、国际查单 / 答复或未收声明，填写关联卡号、袋号、原单号、事项、附件和答复。
复验须关联原验单；结案须填写答复。生成文书时会填入现有 QSL 与物流资料。

七、备份、恢复与数据范围
默认正式资料目录：%LOCALAPPDATA%\QslPost\Data
默认查询缓存目录：%LOCALAPPDATA%\QslPost\Cache
在“设置与备份 → 更改目录”可以分别选择资料与查询缓存的位置。更改资料目录会复制台账、备份和旧版资料文件，并以后使用新目录。旧目录可留作备用。查询窗口下次打开时会在新缓存目录创建网页缓存。
主文件为 qsl-post.xml，每次成功保存采用候选副本校验和原子替换，.bak 保留前一版本；backups 目录保留每天首次保存。
设置页面可以导出完整 XML 备份，恢复前会验证编号、关系和历史完整性，并另存恢复前快照。恢复较早版本后，当前资料库已发出的编号也会保留占用。
操作历史有顺序和 SHA-256 完整性链，用于发现误改，不等同于数字签名或司法取证。
本版为单机资料库。同一目录拒绝两个程序同时写入，不作为共享盘多人并发系统。
资料库启动失败时请保留现场文件，从已知备份恢复；不要手工编辑主文件内的操作历史。

八、填单示例
1. 在「卡片台账」单击「登记卡片」。示例通联采用 2026-11-18 10:30 UTC、14.250 MHz、SSB、RST 59／59。请根据实际通联填写发卡呼号和收卡呼号。软件在保存时分配卡号。
2. 在「封发作业」建立邮袋，填写原寄台、寄达台、运输方式及称得的毛重。选中该邮袋，单击「装入卡片」，勾选要随袋封发的卡片。
3. 在「单据中心」搜索 CP85。选择 130 × 90 mm 的原式袋牌。打开打印工作室，选择刚建立的邮袋，核对袋号、目的台和条码。
4. 要出查单，先在「查验与查单」登记事项及关联卡号，再单击「生成文书」。在打印工作室分别查看正面和背面，导出一份 PDF。
5. 需要手填纸质表单时，在打印工作室选择「空白单据」并导出。需要填写名址时，可参看本手册的「名址填写示例」。

九、运行环境与已知测试范围
原生 Windows x86 / .NET Framework 4.0 构建。Windows 10/11 通常已有 4.x；其他系统需安装 Full 运行库和对应打印机驱动。
XP 目标为 32 位 Windows XP SP3 + .NET Framework 4.0 Full。它是兼容构建目标，未进行真实 XP 机器验证，不能视为已通过所有 XP 驱动和联网测试。
本机测试系统为 Windows 11 x64。Windows 10、7、XP 尚待设备测试。内置 PDF 验证页面尺寸并回读条码。实体出纸位置和扫码效果请按所用打印机确认。
已用 17TRACK 的公开示例单号检查内置查询窗口。
